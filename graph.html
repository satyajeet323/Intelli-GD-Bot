🔄 Key Workflows

🚀 Session Creation & Join Flow

1. Host creates session
POST /api/sessions → Gemini generates topic → sessionId returned (e.g. ABCD-EFGH-IJKL)
2. Host shares session ID
Participants navigate to /group-session/:sessionId
3. Validate session
GET /api/sessions/:id/validate → confirm session exists and is active
4. Join via REST
POST /api/sessions/:id/join → marks participant as active in MongoDB
5. Socket.io connect
emit join-session → server adds to room, broadcasts peer-joined to others
6. WebRTC negotiation
New peer sends offers to all existing peers → ICE exchange → P2P streams established
7. Session active
All participants see each other's video/audio. Chat and AI panel available.

🎙️ Audio Analysis & Scoring Flow

1. Capture audio
Browser MediaRecorder captures participant's microphone stream
2. Upload to ML server
POST /api/gd/turn with audio blob + sessionId + topic
3. Audio preprocessing
ffmpeg converts to 16kHz mono WAV → split into 15s chunks
4. Parallel processing
ElevenLabs STT (primary) + CRNN filler detection + prosody analysis run concurrently
5. Semantic scoring
sentence-transformers computes cosine similarity between transcript sentences and topic
6. Gemini scoring
Gemini 2.5 Flash evaluates vocabulary, grammar, coherence, clarity, prosody metrics
7. Score aggregation
PATCH /api/reports/:id/turn → scoreCalculator.js computes weighted overall score

⭐ Session End & Peer Rating Flow

1. Host ends session
POST /api/sessions/:id/end → status set to "ended", endedAt recorded
2. AI report generated
POST /api/gd/report → Gemini generates personalized feedback for each participant
3. Peer rating modal
PeerRatingModal shown to each participant to rate others (1-5 on 4 criteria)
4. Submit ratings
POST /api/peer-ratings/:id → stored in session.peerRatings array
5. Aggregate scores
peerScore = avg(communication+relevance+confidence+clarity)/4 × 2 → 0-10 scale
6. Combined score
combinedScore = (overallScore × 0.7) + (peerScore × 0.3)
7. View report
Navigate to /report/:sessionId → full breakdown with charts and feedback

🤖 AI Discussion Partner Flow

1. Session initialized
POST /api/gd/session/start → Gemini session memory created with topic context
2. User speaks/types
Audio captured or text typed in AIPanel component
3. STT (if audio)
ElevenLabs STT converts speech to text with Whisper fallback
4. Gemini responds
POST /api/gd/chat → Gemini generates contextual discussion response
5. TTS (optional)
POST /api/tts → ElevenLabs converts AI response to speech
6. Real-time scoring
Each turn scored and aggregated → running performance metrics updated

🧠 ML Pipeline

🔊 CRNN Filler Detector

Custom trained model for detecting filler words in speech audio segments.

PropertyValue
ArchitectureConv2D → GRU (bidirectional) → Classifier
InputMel-spectrogram (128 bins, 2584 frames)
OutputBinary: filler / non-filler per segment
Segments6 audio segments per audio file
ReturnInteger 0-6 (filler segment count)
Model filefiller_crnn_final.pth
FrameworkPyTorch 2.5 + torchaudio

📐 Semantic Relevance Scorer

Measures how on-topic the participant's speech is relative to the GD topic.

PropertyValue
Modelall-MiniLM-L6-v2 (sentence-transformers)
MethodCosine similarity per sentence
Threshold≥ 0.50 similarity = relevant
Scoring85%+ relevant → 10, proportional below
Final scoreavg(proportion score, mean similarity)
OutputInteger 1-10
